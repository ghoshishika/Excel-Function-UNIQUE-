# 📊 Extract Unique Values in Excel (Without UNIQUE Function)

## **🧐Scenario**
**Many users depend on the UNIQUE() function (Excel 2021 / 365).**

**But what if you're using an older version of Excel?**

## **💡Just A little help**

Here’s how I extracted unique Department names using Advanced Filter:

🔹 Step-by-Step Process:

1️⃣ Select the entire dataset

2️⃣ Go to Data tab

3️⃣ Click on Advanced Filter

4️⃣ Choose “Copy to another location”

5️⃣ In List Range, select the column where you want unique values
(For me: Department column)

6️⃣ Tick ✅ “Unique records only”

7️⃣ In Copy To, select the destination cell
(For me: Cell E4)

8️⃣ Hit up the Botton OK

**✨ And Excel instantly gives unique values — no UNIQUE function needed!**

## **📄Note**

**✔️Understanding both modern functions and traditional Excel tools helps**

**in real-world scenarios where newer functions may not be available.**
